# 星索 StarIndex · 界面规范

2026-11-19 按用户要求升级为清爽科技风。采用 ui-ux-pro-max 中已核实适用于后台的 Minimalism & Swiss Style、首页 Hero-Centric 构图和 Vue 异步副作用清理建议。检索到的新闻类红色配色与产品定位不符，不采用；保留本机字体与 Telegram iOS Icons，避免外部字体依赖。

- 白色侧栏/卡片，页面底色 #f5f8fc，主色 #2859e8，正文 #14243d，次级正文 #5e6f86，边框 #e3eaf2。深海军蓝 #142b50 用于品牌、工作台欢迎区和余额卡；青色 #087d9b 作为少量辅助色。
- 桌面侧栏 244px、顶栏 78px，内容边距 36px；平板 24px、手机 20px，手机侧栏使用可关闭抽屉。视觉更新集中在 `frontend/src/experience.css`，复用业务组件和路由。
- 后台侧栏采用可折叠的多级导航，目前使用一级入口与二级页面，组件保留递归扩展能力。菜单行高至少 44px，每层缩进 16px；当前页面用浅蓝背景、左侧标记和文字加粗，祖先目录浅蓝提示。刷新和直接进入深层页面自动展开祖先；空权限目录隐藏，面包屑同步层级，手机只展示当前页标题。
- 「用户管理」为独立一级菜单，位于「内容管理」之后；「管理员管理」和「角色与权限」直接作为「系统管理」下的二级菜单，不设置「账号与权限」中间目录。
- 主按钮、输入框、下拉框统一 42px；移动端 44px。表格操作按钮视觉尺寸 32px，点击区域至少 32px，移动端 44px。
- 间距按 4/8/12/16/24/32px，卡片圆角 16px，控件圆角 10px。每个页面一个主要行动按钮。桌面首页采用左文案与搜索、右静态连接示意，移动端隐藏装饰示意以优先展示搜索。
- 机器人连接页的操作栏与信息表间距 24px，桌面按钮间距 16px，可按内容换行；手机上下等宽排列、间距 12px、最小高度 44px。链接呈按钮样式时保留单一链接语义，避免在链接内嵌套按钮。
- 字体使用本机 system-ui / PingFang SC / Microsoft YaHei，避免外部字体网络依赖。正文 14–16px，页面标题 26px，数据 30px。数字使用 tabular-nums。
- 图标统一使用 Telegram iOS Icons（tgiosicons）。Telegram 使用原始 custom emoji ID；网页使用同一图标的 TGS 第 0 帧导出 SVG，并通过 currentColor 遮罩着色，不重绘、不使用模糊缩略图。导航包含文本，状态由文字和颜色共同表达。
- 必须提供加载、空数据、错误重试、提交成功状态。危险操作有确认框；表单错误在字段旁展示。
- 后台实体列表首列展示真实数据库 ID，采用等宽数字，不使用页面序号代替。筛选栏提供独立 ID 查询；操作区采用「查看 / 编辑 / 更多」，按钮之间留 8px，删除等低频操作在更多菜单内。手机筛选按钮等宽排列；详情抽屉内长链接和权限内容换行，表格横向滚动局限在表格容器内。
- 支持键盘操作和可见焦点；尊重 reduced-motion。375px 和横屏检查布局，不依赖 hover 才可操作。
- 仪表盘只显示数据库真实数据；没有记录时提供空状态，不生成虚构趋势或增长比例。
- Telegram 登录采用用户主动发起、机器人明确确认、网站消费一次性挑战的交互；请求凭据只保存在页面内存。取消、切换方式和离开页面停止轮询。一次性登录码作为备用方式保留。
- 账户与安全页清楚显示绑定状态和解绑定条件；不自动合并不同账户余额。设置首个密码说明 15 分钟登录时效；解绑需要验证网站密码。
- 角色配置提供模块搜索、授权数量、隐藏/只读/可编辑说明和按模块只读授权、清空授权。前端可见性仅辅助交互，授权始终由服务端决定。
