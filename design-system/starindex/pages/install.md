# 初始化安装页

沿用 MASTER.md 的白底蓝色、本机字体、Telegram iOS Icons 和 42px 控件；手机控件为 44px。四步向导使用独立页面，不嵌套网站或后台导航。

- 桌面以左侧步骤和右侧白色表单卡片组织内容，手机将步骤收为顶部四列，优先显示当前任务。
- 环境、数据库和账号分步展开。每步只有一个主要按钮；返回保留输入，连接信息变化后必须重新测试。
- 采用 ui-ux-pro-max 的表单提交反馈、明确标签和返回状态保留规则，复用 Element Plus Form 校验。错误同时出现在字段与可聚焦的摘要区域。
- 安装码和密码只保存在页面内存，不写入 localStorage/sessionStorage，使用密码输入框；安装完成时清空。
- 安装中禁用重复提交；网络失联后先读取实际安装状态，再选择进入后台或继续原任务。
- 已检查 375px 手机及 812px 横屏无横向溢出，所有图标均为既有 Telegram iOS 图标。
