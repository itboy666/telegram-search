# 机器人搜索验证与群组安全

## 后台入口

在「机器人管理」中：

- **搜索验证**（`/admin/bot-security`）：分别设置私聊验证和群聊默认验证。关闭「允许群管理员自主配置」后，所有群执行后台群聊规则，群命令不能覆盖。
- **群组安全**（`/admin/bot-groups`）：查看真实数据库 ID、Telegram 群 ID、邀请人、机器人群身份、删除权限、群规则、成功删除数与最近拦截错误。支持编号/关键词查询、分页、详情与规则编辑；群身份和邀请人由 Telegram 事件登记，不开放人工伪造。
- 新增独立权限模块 `bot_security`、`bot_groups`，均区分查看与修改，并逐字段授权。写接口检查管理员会话、CSRF 和字段权限，修改写入操作日志。

首次升级默认私聊/群聊均不验证，允许群管理员自主开启；广告和消息刷屏拦截默认关闭。搜索限流一直存在。可以先在测试群开启，再决定是否全局强制。

## 群管理员命令

入群的 `my_chat_member` 事件会记录邀请人、群名和机器人权限，并发送一次配置指引。已加入的群可由管理员发送 `/groupsettings` 登记。

| 命令 | 用法 |
| --- | --- |
| `/groupsettings` | 查看本群生效策略和命令说明 |
| `/captcha emoji` | 搜索前选对 emoji |
| `/captcha button` | 点击确认，轻量验证 |
| `/captcha text` | 回复图片中的六位字母数字，不区分大小写 |
| `/captcha math` | 回复加减乘除题答案，结果为非负整数 |
| `/captcha sequence` | 按指定顺序点击三个 emoji |
| `/captcha random` | 从 emoji、图片、算术和顺序题中随机选择 |
| `/captcha off` | 关闭本群验证，仅在后台允许自主配置时有效 |
| `/captcha inherit` | 恢复继承后台群聊策略 |
| `/ads on` 或 `/ads links` | 删除普通成员消息中的非允许域名链接 |
| `/ads keywords` | 删除包含配置关键词的普通成员消息 |
| `/ads strict` | 同时启用链接与关键词规则 |
| `/ads off` | 关闭广告拦截 |
| `/adwords 关键词一\|关键词二` | 设置关键词；`clear` 清空 |
| `/allowdomain example.com\|example.org` | 设置允许的域名；`clear` 清空 |
| `/flood on` | 每人 10 秒最多 6 条消息，相同文字 30 秒最多 3 条 |
| `/flood 10` | 自定义每人 10 秒内的上限，范围 4–30 |
| `/flood off` | 关闭群消息刷屏拦截 |

命令均支持 `@机器人用户名` 后缀，发给其他机器人的命令不执行。每次配置均向 Telegram 查询操作者当前身份，只有群主及当前管理员能修改。邀请人离任后没有永久权限；匿名管理员必须切换为个人身份配置。

启用群拦截前，应把机器人设为群管理员并授予删除消息权限。群命令会核对权限；若后台预先保存规则但未授权，后台显示失败原因，不将删除失败计为成功。配置命令每人每群限 6 次/分钟。

## 验证与防刷行为

- 验证发生在搜索前，涵盖普通关键词、`/search`、`/discover` 和菜单搜索。不是所有入群成员必须立即验证的入群审核。
- 题目绑定机器人 ID、Telegram 用户 ID、聊天 ID、题目消息 ID；话题群还检查话题 ID。别人不能代答、消耗你的次数或复用你的通过状态。
- 每名用户在每个聊天只保留一题。连续发送关键词不会新增验证消息或重置次数；默认 180 秒有效，最多答错 3 次，失败后冷却 300 秒。每人每聊天最多生成 3 题/分钟。
- 按钮回调仅携带随机题号与随机选项键，正确答案以哈希保存。图片由本机 PHP GD 生成并在内存中通过 multipart 上传；答案不出现在图片说明或文件名中。
- 顺序题答错后从头开始，但累计答错次数保留；算术没有除零或小数结果。
- 私聊数字/图片答案可以直接输入；群聊必须回复自己的题目消息，并处于同一话题，避免误把普通数字聊天当成答案。
- 通过后自动继续原搜索，该次搜索不会重复扣额。默认在当前聊天免验证 30 分钟；私聊与不同群互不共享。后台更改策略会使旧通过状态重新校验。
- 验证过期或后台要求加强时，旧搜索结果也不能继续绕过验证翻页；提示重新发送关键词。
- 默认每人每分钟 30 次搜索操作、每群每分钟 20 次，覆盖首次搜索、题目发送、翻页和筛选；恢复已验证的原搜索使用之前预留的额度。同一限流提示最多每 10 秒发送一次。
- 现有消息入口另有每人 30 条/分钟、菜单回调 40 次/分钟的基础限制。后台搜索上限不能提高这些基础限制。

点击确认、emoji 与普通算术都可能被脚本自动完成；图片验证码也可能被 OCR 识别。它们提高交互门槛，不能作为“绝对真人”的证明。本实现依靠身份绑定、限次、冷却、单题复用及限流共同降低滥用。未接入外部 Turnstile、设备指纹或跨站身份追踪服务。

## 广告规则的边界

- 链接规则检查正文和媒体说明中的显式链接、Telegram URL 实体、隐藏文字链接，兼容 Telegram 使用的 UTF-16 实体偏移；编辑已有消息同样检查，编辑不会再触发搜索。
- 这是明确的内容规则，不是自动判断商业广告语义。开启链接模式会拦截普通成员所有未允许的链接；允许 `t.me` 会放行整个 Telegram 域名。域名允许其真实子域，不匹配 `allowed.example.evil.test` 这样的相似域名。
- 关键词为管理员填写的字面包含匹配，最多 50 行，每行 2–60 字，不执行用户提供的正则表达式。
- 群主、当前管理员、以群身份发言的匿名管理员及关联频道自动转发免拦截。身份检查失败时不删除，停止将该疑似广告继续作为搜索，并记录错误。
- 消息刷屏规则对超过次数的当前消息执行删除，不自动禁言、踢人或封禁账号。删除消息不可恢复，需按群用途选择规则。
- Bot API 无法让机器人获得未被投递的消息。实际拦截效果依赖机器人所在群的权限和 Telegram 的消息投递；本地模拟测试不等同于真实多人群验收。

## 安装、运行与维护

```sh
php think app:upgrade-bot-security
# 已有长轮询需重启加载代码
php scripts/dev.php stop
php scripts/dev.php
```

迁移 `005_bot_security` 可重复执行，仅新增 `ts_bot_groups` 和 `ts_bot_verifications`；全新安装由 `app:install` 自动执行。查询按机器人、聊天和用户索引，验证状态修改使用事务与行锁。MySQL 8.0 兼容，不依赖特定新版数据库功能。

图片验证码需要 PHP GD，本机已安装。长轮询接收 `message`、`edited_message`、`callback_query` 和 `my_chat_member`；启动时更新默认及群管理员命令菜单。Token 仍使用后台原有加密配置。

`php think app:maintain` 同时清理过期验证记录。验证码状态不通过后台接口返回，也不进入通用设置接口。

验证命令：

```sh
php tests/bot_security.php
php tests/bot_security_http.php
php tests/bot_menu.php
php tests/bot_groups.php
php tests/bot_search.php
php tests/catalog_identity.php
php tests/integration.php
php tests/admin_rbac.php
```

Telegram 协议依据：官方 Bot API 的 `getChatMember`、`my_chat_member`、`deleteMessage`、`sendPhoto`、`setMyCommands` 与 `getUpdates`。本次读取的官方接口页为 `https://core.telegram.org/bots/api`。
